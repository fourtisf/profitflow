# ProfitFlow

A real-time terminal for **realized profit** on Solana. Everyone tracks whale *buys*; ProfitFlow
tracks the *cash-out* — wallets taking money off the table, ranked by USD, the moment a sell clears.
The growth loop is a feed you keep open plus auto-generated share cards that distribute themselves.

> **Spec / source of truth:** [`HANDOFF.md`](./HANDOFF.md) — product spec, locked decisions, and the
> original build tasks. This README covers the built monorepo: how to run, deploy, and what's wired.

**To take it live you provide:** a Helius key, a historical price key (Birdeye/Pyth), Postgres +
Redis, Vercel auth, a VPS + domain, and Telegram/X creds. Everything is wired to activate by env —
no code changes (see [Going live](#going-live)).

## Architecture

```
packages/
  pnl-engine   pure realized-PnL math (avg cost + FIFO). THE source of truth. Used everywhere.
  shared       types · thresholds · DataSource interface · SimDataSource (dogfoods the engine)
apps/
  web          Next.js 14 — landing, live feed (WS), share cards, pricing, waitlist, OG images
  api          REST + WebSocket feed. createDataSource(sim | helius). Tier gating.
  worker       Helius -> parse -> engine -> Redis (hot positions) -> emit Postgres + Redis pub/sub
  bot          hourly: biggest exit -> /api/card -> Telegram + X
```

**Data flow (live):** `worker` ingests + emits to Postgres/Redis → `api` live-tails Redis and serves
REST/WS → `web` renders the feed → `bot` posts the biggest exit hourly.

### The demo-vs-live seam (how it ships today)

All data access sits behind one `DataSource` interface, chosen by `DATA_SOURCE`:

- **`sim`** (default) — realistic fake events, generated by running synthetic trades through the
  **real engine**. No keys. The site deploys and looks alive immediately.
- **`helius`** — real ingest. Flip the env once keys + infra are ready.

The frontend never knows which is active. The web feed even falls back to an in-browser sim if no
API is configured, so the Vercel deploy is alive on day one.

## Quick start

```bash
pnpm install
pnpm test          # engine (14) + shared (14)
pnpm typecheck
pnpm build

# Run the full demo locally (two terminals):
pnpm --filter @profitflow/api dev      # http://localhost:4000  (sim feed over REST + ws://…/ws)
pnpm --filter @profitflow/web dev      # http://localhost:3000

# Point the web feed at the API:
#   apps/web/.env.local -> NEXT_PUBLIC_API_WS_URL=ws://localhost:4000/ws
```

Each app has its own `README.md` and `.env.example`.

## Validation gate (HANDOFF Task 1)

The engine ships green, but proving it against **real** wallets still gates the live pipeline:

```bash
HELIUS_API_KEY=xxx pnpm validate <WALLET> <TOKEN_MINT> [SOL_USD]
```

Check the printed ledger line-by-line against Solscan. `validate` uses a **flat** SOL price for
sanity only — production pricing is per-timestamp in the worker (the #1 accuracy risk).

## Decisions locked for this build

1. **Monetization:** $29/mo **Pro** subscription (free feed > $10k, Pro from $500). Pricing restored
   on the page; gating enforced in the API. *(Real auth + Stripe billing still to wire.)*
2. **transfer_in:** label **"unverified basis"**, suppress the misleading multiple — never a fake +∞×.
3. **Universe threshold:** **$50k** liquidity floor (`UNIVERSE_LIQUIDITY_FLOOR_USD`).
4. **Domain:** TBD — wired as the single env `NEXT_PUBLIC_SITE_URL` (placeholder `profitflow.io`).

## Going live

**Frontend (Vercel):** import the repo, root `apps/web`, set `NEXT_PUBLIC_SITE_URL` and (once the API
is up) `NEXT_PUBLIC_API_URL` / `NEXT_PUBLIC_API_WS_URL`. Ships in demo mode with no API.

**Backend (VPS):** `docker compose up --build` runs api + worker + bot + Postgres + Redis. Out of the
box it's demo mode (worker pipes sim exits through real Postgres/Redis). To go live, create a `.env`:

```bash
DATA_SOURCE=helius
HELIUS_API_KEY=...
BIRDEYE_API_KEY=...        # per-timestamp SOL price — do NOT ship a flat price
TELEGRAM_BOT_TOKEN=...     # optional, enables the bot
TELEGRAM_CHAT_ID=...
```

Apply the DB schema once: `DATABASE_URL=... pnpm --filter @profitflow/worker prisma:push`.
Front it with [`deploy/nginx.conf`](./deploy/nginx.conf) (TLS + WebSocket upgrade) and point the
domain via Cloudflare.

## Caveats

- The live feed is **simulated** until the worker runs in `helius` mode. The footer says so — don't
  present demo numbers as real.
- Profit figures are estimates from public on-chain data and reconstructed cost basis. Analytics, not
  financial advice.
